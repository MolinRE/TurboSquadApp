# Интеграционный API

Внешняя система может получать из «Турбо-бригады» успеваемость Проводника:
- Очки компетенций и Звание;
- Процент успеваемости в целом и по Темам;
- итоги Рейсов;
- время последней активности.

Авторизация посредством заголовка `X-Api-Key`.

## 1. Сгенерировать ключ

Сформировать уникальный секретный ключ .

- **Docker Compose:** ключ берётся из переменной `INTEGRATION_API_KEY` в `.env`. Если её нет, работает демо-ключ `local_demo_integration_key`
- **`dotnet run`:** ключ задаётся переменной окружения `Integration__ApiKey`.

Если заголовка нет, ключ неверный или ключ не задан на сервере, API отвечает `401 Unauthorized`.

## 2. Успеваемость одного Проводника

`GET /api/integration/employees/{externalId}`

`externalId` — логин Проводника в «Турбо-бригаде», регистр не важен.

```bash
curl -H "X-Api-Key: local_demo_integration_key" \
  http://localhost:5017/api/integration/employees/conductor-star
```

```json
{
  "externalId": "conductor-star",
  "displayName": "Марина Соколова",
  "depot": "Северное депо",
  "brigade": "Бригада 1",
  "competencePoints": 140,
  "rank": "Старший проводник",
  "knowledge": { "encountered": 16, "mastered": 14, "successRate": 0.88 },
  "topics": [
    { "topic": "Конфликты", "encountered": 4, "mastered": 3, "successRate": 0.75 },
    { "topic": "Посадка и документы", "encountered": 7, "mastered": 6, "successRate": 0.86 }
  ],
  "trips": { "finished": 1, "arrived": 1, "failed": 0 },
  "lastActivityAt": "2026-09-27T18:54:25.455211+00:00"
}
```

| Поле | Значение |
| --- | --- |
| `competencePoints`, `rank` | Очки компетенций и Звание, как в профиле Проводника |
| `knowledge` | сколько Единиц знания встречено и сколько освоено. Единицы знания — это Вопросы Смены и Блица и Шаги Рейса |
| `successRate` | Процент успеваемости: доля от 0 до 1 с точностью до 0,01. Если ничего не встречено — `null` |
| `topics` | то же по Темам — показывает, где у сотрудника пробелы |
| `trips` | завершённые Рейсы: `arrived` — Прибытие, `failed` — Срыв |
| `lastActivityAt` | время последней тренировки; `null`, если тренировок не было |

Если такого логина нет или это не Проводник, API отвечает `404 Not Found`.

## 3. Успеваемость подразделения

`GET /api/integration/employees?depot=&brigade=`

Ответ в том же формате, но без `topics`. Оба фильтра необязательны. Значения — названия Депо и Бригады.

```bash
curl -G -H "X-Api-Key: local_demo_integration_key" \
  --data-urlencode "depot=Северное депо" --data-urlencode "brigade=Бригада 1" \
  http://localhost:5017/api/integration/employees
```

## 4. Swagger

Откройте [http://localhost:5017/swagger](http://localhost:5017/swagger). Нажмите **Authorize** и введите ключ в поле `ApiKey`. Методы собраны в группе «Интеграция», их можно вызвать прямо из браузера.

## Сценарий: HR проверяет готовность к рейсу

1. Проводник Марина (`conductor-star`) за неделю проходит Смену на свайпах, Блиц и один Рейс. Рейс заканчивается Прибытием.
2. Раз в сутки HR-система запрашивает `/api/integration/employees?depot=Северное депо`. Она сохраняет у себя Очки, Звание и `successRate` каждого сотрудника и отмечает тех, у кого `lastActivityAt` старше 7 дней.
3. Руководитель открывает карточку Марины в HR-системе. Та запрашивает `/api/integration/employees/conductor-star` и показывает разбивку по Темам. «Конфликты» — 0,75: это ниже остальных Тем.
4. Руководитель назначает Марине Рейс с Событиями на Тему «Конфликты». После тренировки растут `topics[].successRate` и `trips.arrived`.

## Ограничения

- `externalId` — это логин: отдельной колонки для внешнего идентификатора в базе нет. Заводя учётные записи, задавайте логин равным табельному номеру или логину в HR-системе.
- Импорт сотрудников из HR-системы и экспорт в xAPI не сделаны: их урезали до сдачи.
