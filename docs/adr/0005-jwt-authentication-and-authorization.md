# Аутентификация API через stateless JWT

API использует Bearer JWT без серверных сессий: регистрация и вход доступны анонимно, пароль хранится только в виде хеша, а успешный вход выдаёт подписанный токен с идентификатором пользователя, логином, ролями и сроком действия. ASP.NET Core проверяет подпись, issuer, audience и срок действия токена; защищённые методы требуют валидный токен, а методы с ролевой политикой дополнительно требуют соответствующую роль. Ключ подписи и параметры JWT задаются конфигурацией, а `/api/auth/me` и role-check методы защищены, тогда как регистрация, вход и `/api/events/validate` остаются публичными.
