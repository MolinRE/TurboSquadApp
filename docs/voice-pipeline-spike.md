# Спайк голосового конвейера

Дата проверки: 26.09.2026.

## Конфигурация

- STT base URL: `https://polza.ai/api/v1`
- STT model: `ai-sage/gigaam-v3`
- LLM model: `qwen/qwen3.6-35b-a3b`
- Laya endpoint: `http://176.108.247.22:8000/v1/systemone`
- Laya health: `status=ok`, `device=cpu`, загружен checkpoint `multilingual`
- Ключ polza берётся из `POLZA_API_KEY`.
- Токен Laya берётся из `LAYA_API_TOKEN`; для текущего локального `.env` также поддержан фактически присутствующий alias `LAYA_API_KEY`.

## Подтверждённые контракты

### polza.ai

`GET /models` отвечает `200` и содержит обе модели:

- `ai-sage/gigaam-v3`;
- `qwen/qwen3.6-35b-a3b`.

Вызов STT через `POST /audio/transcriptions` с multipart-полем `file` и полем `model` дошёл до провайдера, но получил `402 INSUFFICIENT_BALANCE`.

Вызов Qwen через `POST /chat/completions` с OpenAI-совместимым JSON также дошёл до провайдера, но получил `402 INSUFFICIENT_BALANCE`.

Следовательно, формат запроса и авторизация подтверждены частично; успешная расшифровка и потоковая генерация требуют пополнения баланса.

### Laya

Сервис предоставляет:

- `GET /health`;
- `POST /v1/systemone`;
- Bearer-авторизацию;
- System One payload с `state` и `questions`.

Для `choice` ответ имеет поля `choice`, `probabilities`, `confidence`, `answer_confidence`, `action` и `usage`.

Минимальный рабочий запрос для `sit-06/s1` использует три варианта `a`, `b`, `c`. Первый вызов вернул `choice=a` за 216 мс.

## Golden set

Предварительный набор содержит 20 вручную размеченных русских реплик для `sit-06/s1`:

- 5 спокойных деэскалаций, ожидаемый вариант `a`;
- 5 вариантов бездействия, ожидаемый вариант `b`;
- 5 агрессивных реакций, ожидаемый вариант `c`;
- 5 коротких или неоднозначных ответов.

Разметка предварительная и требует пересмотра методистом перед использованием как продуктового эталона.

## Результаты Laya

| Показатель | Результат |
|---|---:|
| Обработано | 20/20 |
| Правильные `choice` | 11/20 |
| Accuracy | 55% |
| p50 latency | 149 мс |
| p95 latency | 156 мс |
| `answer_confidence < 0.7` | 14/20 |
| `answer_confidence >= 0.7` | 6/20 |
| Правильные среди `answer_confidence >= 0.7` | 6/6 |

## Решение спайка

Критерий общей точности 80% не пройден. Для MVP Laya можно использовать только через confidence gate с fallback на кнопки, но покрытие голосом будет около 30% на текущем наборе.

До пополнения polza и получения настоящих аудиозаписей нельзя закрыть проверку STT и потокового Qwen. Тикет остаётся открытым до повторного прогона.

## Дополнительная проверка checkpoint

Сервер изначально загрузил только `multilingual`. Явный запрос с `model=typed-decisions` успешно отработал и дозагрузил checkpoint:

- холодный первый вызов: 17,2 с;
- прогретый повторный вызов: 717 мс;
- один очевидный пример классифицирован как `a`;
- `answer_confidence` примера: 0,5229.

Этого недостаточно, чтобы объявить `typed-decisions` лучше. Для сравнения нужен полный одинаковый golden set, прогретый сервер и отдельная проверка точности, покрытия и latency. Для демо checkpoint следует предварительно загружать, чтобы холодная загрузка не попадала в голосовой Шаг.

## A/B-тест входного формата и checkpoint

Проведён одинаковый тест на 15 явных репликах: по 5 для каждого Варианта `a`, `b`, `c`. Неоднозначные реплики исключены. Сравнивались плоское поле `body` и структурированные поля `situation` + `conductor_response`.

| Checkpoint | Формат | Accuracy | p50 | p95 |
|---|---|---:|---:|---:|
| `multilingual` | `body` | 5/15 (33%) | 218 мс | 225 мс |
| `multilingual` | structured | 8/15 (53%) | 213 мс | 219 мс |
| `typed-decisions` | `body` | 5/15 (33%) | 934 мс | 1083 мс |
| `typed-decisions` | structured | 8/15 (53%) | 911 мс | 952 мс |

Текущий рабочий вариант для следующего цикла — `multilingual` со структурированным входом. Он дал ту же точность, что `typed-decisions`, но примерно в четыре раза меньшую задержку на прогретом CPU. Ни один вариант пока не достигает целевой точности 80%.

Продуктовые fallback-режимы в этот тест и в план Голосового конвейера не входят. Ошибка STT, Laya или LLM должна быть явной ошибкой попытки, без продвижения Рейса.
