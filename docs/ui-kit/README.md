# UI-kit «Турбо-Бригады»

Прежде чем делать новый UI-компонент, проверьте этот файл: возможно, нужное уже есть. Новые блоки попадают сюда после того, как прототип экрана утверждён.

Стек: Next.js 16, Tailwind CSS v4, shadcn/ui (база Radix, пресет Nova), иконки lucide-react. Код — в [front/](../../front/).

## Тема

Только светлая. Токены лежат в [front/src/app/globals.css](../../front/src/app/globals.css), в классах используются через имена Tailwind: `bg-brand`, `text-danger`, `bg-heat-1` и т. д.

| Токен | Цвет | Где |
|---|---|---|
| `background` | `#ECEBEA` | Фон приложения (фон vsm400.ru) |
| `canvas` | `#E2E0DC` | Поле вокруг телефонной колонки на широком экране |
| `card` | `#FFFFFF` | Карточки |
| `primary`, `foreground` | `#2E354B` | Основные кнопки, текст, тёмные плашки (Рейс дня) |
| `muted-foreground` | `#5E6476` | Второстепенный текст |
| `brand` / `brand-light` / `brand-soft` | `#038681` / `#54AEA4` / `#E0F0EE` | Акцент ВСМ: активные элементы, «верно», прогресс |
| `danger` / `danger-soft` | `#DA2032` / `#FBE3E5` | Срыв рейса, критическая ошибка, падение Шкалы |
| `warning` / `warning-foreground` / `warning-soft` | `#FF6803` / `#A84300` / `#FFE8D9` | Таймер на исходе, Шкала в опасной зоне. Для текста только `warning-foreground` |
| `heat-1…4`, `heat-low` | см. `globals.css` | Тепловая карта: < 50%, 50–64%, 65–79%, ≥ 80%, мало данных |
| `sidebar-*` | `#2E354B` и др. | Тёмное боковое меню рабочего места |

- **Скругление:** `--radius: 0.75rem`. Кнопки `rounded-lg` (12px), карточки `rounded-xl` (~17px, как на vsm400.ru).
- **Шрифт:** Manrope через `next/font/google`. Фирменный MoscowSans Московского транспорта не подключён: лицензия не проверена.
- **Цифры** в колонках и счётчиках: `tabular-nums`.

Откуда цвета: палитра выкачана из CSS vsm400.ru, красный и оранжевый — transport.mos.ru и mosmetro.ru. Эскиз, на котором стиль согласовывали: [etalon.html](etalon.html) (открывается двойным кликом; опубликованная копия — https://claude.ai/artifact/MpZVzEx7VZU2WQW7157oef).

## Шаблоны страниц

Каждый шаблон — layout группы маршрутов в `front/src/app/`.

| Шаблон | Группа | Устройство | Каркас |
|---|---|---|---|
| Вход | `(auth)` | любое | Логотип и одна колонка по центру |
| Приложение проводника | `(player)` | телефон | `PlayerHeader` (аватар, Бригада) + нижние вкладки `PlayerTabBar` |
| Игра | `(game)` | телефон | `GameTopBar` (выход и название). Шкалы и таймер рисует сама игра |
| Рабочее место | `(workspace)` | десктоп | `AppSidebar` (тёмное меню: Аналитика, Контент) + `WorkspaceHeader` |

Компоненты каркаса лежат в `front/src/components/shell/`.

## Карта экранов

Единственный источник — [front/src/lib/screens.ts](../../front/src/lib/screens.ts): путь, шаблон, роль, этап и что должно быть на экране. Из него строятся боковое меню, заголовки и заглушки. Новый экран сначала добавляется туда.

Пока экран не сделан, на его месте `ScreenPlaceholder` — пунктирная карточка «Что здесь будет».

## Компоненты shadcn/ui

Установлены: `avatar`, `badge`, `button`, `card`, `dropdown-menu`, `input`, `progress`, `separator`, `sheet`, `sidebar`, `skeleton`, `tooltip`. Остальные добавляются командой `npx shadcn@latest add <имя>` из папки `front/`.

## Доменные блоки

Появились вместе с экраном Смены на свайпах.

| Блок | Компонент | Правила |
|---|---|---|
| Шкала | `ScaleMeter`, `ScalesPanel` в `front/src/components/game/scale-meter.tsx` | Название, значение, плашка изменения от последнего решения (`−` красным, `+` бирюзовым), полоса с отметкой старта. Цвет полосы: бирюзовый, от половины до четверти над порогом Срыва — `warning`, ниже четверти — `danger`. Общая для всех игр |
| Иконка Темы | `TopicIcon` в `front/src/components/game/topic-icon.tsx` | Иконка lucide на каждую Тему PRD §7.1; у новой Темы из справочника — общая иконка |
| Карточка-свайп | `SwipeCard` в `front/src/components/swipes/swipe-card.tsx`, жест — `useSwipeDrag` | Высота по тексту. В шапке — прогресс точками и таймер. Формулировка печатается (`TypedText`), и только потом появляются варианты и идёт таймер. Свайп работает в любой части игрового экрана, кроме кнопок. Одна полярность: вправо — «да / можно / сделать», влево — «нет / нельзя», вверх — «Не знаю». Ответ засчитывается после смещения на 96 px, до порога карточка возвращается; пока тянут, штамп посередине карточки показывает, каким будет ответ. Под карточкой видны края следующих — колода. На первой карточке в браузере карточка один раз сама качается вправо, влево и вверх со штампами. Повтор помечен бейджем «Повтор» в `warning-soft` рядом с Темой. Под ней: «Не знаю» тонкой строкой во всю ширину (свайп тоже вверх), под ней два крупных варианта. После ответа карточка улетает сразу; если сервер отвечает дольше полсекунды, на её месте жирное «Сверяем ответ…» `muted-foreground`. Ответ не дошёл — карточка возвращается, таймер стоит, под вариантами красным «Ответ не отправлен: …» и кнопка-outline «Отправить ещё раз» на `card`. Ответ уже был засчитан раньше (результат потерялся в сети) — следующая карточка и под вариантами строка `muted-foreground` «Ответ на прошлую карточку уже был засчитан — продолжаем.». Не удалось начать Смену или вернуться к ней — посередине экрана красная строка с причиной, под ней «Попробовать снова» и outline «Новая Смена» |
| Пояснение | `VerdictLabel`, `ExplanationText`, `SourceLine` в `front/src/components/swipes/explanation.tsx` | Вердикт: «Верно» бирюзовым, «Неверно» красным, «Не знаю» и «Время вышло» — `warning-foreground`, рядом время ответа. Ключевой факт жирным, ниже «Источник: …» мелко. Панель после ответа, в её шапке тот же прогресс точками: после ошибки, «Не знаю» и «Время вышло» ждёт «Понятно», после верного — кнопка «Дальше» с убывающей полоской и сама уходит через паузу. В Циклах 2–3 после верного ответа панели нет |
| Вопрос Блица | `QuestionCard` в `front/src/components/blitz/blitz-session.tsx` | Карточка `card`: в шапке прогресс точками (`DeckProgress`) и `Countdown` от показа Вопроса. Под ней бейдж Темы с `TopicIcon`, формулировка жирным `text-lg` без печати, варианты — outline-кнопки во всю ширину, текст переносится. `single`: нажатие сразу отвечает. `multiple`: под формулировкой «Верных несколько — отметьте все» `muted-foreground`, варианты — переключатели (`aria-pressed`) с `Square` / `SquareCheck`, отмеченный — рамка `brand` на `brand-soft`; под ними тёмная «Ответить» во всю ширину, неактивна, пока ничего не отмечено. `sequence`: подсказка «Нажимайте шаги по порядку, с первого. Повторное нажатие убирает шаг», шаги — такие же переключатели; поставленный шаг — рамка `brand` на `brand-soft` с номером в круге `brand`, ещё не поставленный — пунктирный круг; «Ответить» активна, когда расставлены все шаги. После ответа выбранные варианты обведены `foreground`, под вариантами «Сверяем ответ…» `muted-foreground`. Истёк отсчёт — «Время вышло», как у Смены, отметки не отправляются |
| Ответ Блица | `FeedbackPanel` в `front/src/components/blitz/blitz-session.tsx` | Та же шапка, что у Пояснения Смены: прогресс, вердикт, «Ответ за N с». Варианты списком: верный — рамка `brand` на `brand-soft` с `CircleCheck`, выбранный неверный — рамка `danger` на `danger-soft` с `CircleX`, остальные `muted-foreground`. У `multiple` верный, но не отмеченный вариант справа подписан «Не отмечен» `muted-foreground`. У `sequence` — шаги в верном порядке с номером: на своём месте — `brand-soft` с `CircleCheck`, не на своём — `danger-soft` и справа «У вас №N» `danger`; при «Время вышло» — все `brand-soft` без отметок. Ниже Пояснение с ключевым фактом и «Источник: …». Сам не уходит: следующий Вопрос и его таймер — по «Дальше», после последнего — «К итогу». Итог — «Блиц пройден», «Верно: N из M», среднее время и «Что повторить» из итога Смены |
| Печатающийся текст | `TypedText` в `front/src/components/game/typed-text.tsx` | Текст появляется за заданное время, место под него занято сразу; при «уменьшении движения» виден целиком, но onDone ждёт то же время |
| Секундомер и обратный отсчёт | `Stopwatch` и `Countdown` в `front/src/components/game/` | Справа в шапке карточки. Секундомер — пилюля `m:ss` для режима без лимита. Обратный отсчёт — кольцо с секундами, последние 2 с оранжевое; до конца печати оба приглушены |
| Прогресс колоды | `DeckProgress` в `front/src/components/swipes/deck-progress.tsx` | Точка на Вопрос: отвеченные окрашены вердиктом первого ответа (бирюзовый, красный, оранжевый), текущая тёмная, впереди серые; рядом «3/10» — сколько Вопросов закончено. Повтор точку не добавляет, и тёмной точки у него нет |
| Фон-подсказка свайпа | `SwipeAnywhereHint` в `front/src/components/swipes/swipe-shift.tsx` | В пустой зоне под кнопками: рука покачивается между стрелками ←, ↑, →, подпись «Смахивайте в любом месте экрана», всё `muted-foreground` на 45%. Касания проходят сквозь неё; если места меньше 128 px, не показывается |
| Итог Смены | `ShiftSummary` в `front/src/components/swipes/shift-summary.tsx` | Карточка исхода: иконка, «Смена пройдена» или «Срыв смены» с упавшей Шкалой, «Верно с первого раза: N из M», среднее время; под ней Шкалы. «В своём темпе» с ошибками — секция «Что повторить» с числом: по Вопросу формулировка `muted-foreground`, Пояснение с ключевым фактом, «Источник: …»; затем тёмная кнопка «Работа над ошибками» во всю ширину, под ней «Новая Смена» и «К играм» в ряд. Без ошибок нет ни секции, ни кнопки. «На скорость» между Циклами — та же карточка исхода, плашка `brand-soft` «Дальше — Цикл N» и кнопка «Начать Цикл N»; после последнего — таблица сравнения Циклов (верно, Срыв, среднее время) |
| Выбор режима | `ModeChoice` в `front/src/components/swipes/mode-choice.tsx` | Карточки-кнопки: иконка в круге `brand-soft`, название, одна-две фразы, зачем режим, и строка-мета бирюзовым |
| Диалог Рейса | `Dialog`, `PassengerBubble`, `YouBubble` в `front/src/components/game/trip-game.tsx` | Карточка `card` с разговором за весь Рейс: плашка `secondary` с названием События, ситуация Шага (текущая — жирным `text-base`, прошлые — `muted-foreground`), реплики. Пассажир — пузырь слева `brand-soft`, скругление 4/16/16/16, подпись «ПАССАЖИР» бирюзовым капсом; уточнение — `warning-soft` и «ПАССАЖИР УТОЧНЯЕТ» `warning-foreground`; пока пишется — «печатает…», затем текст потоком с курсором. Проводник — пузырь справа `primary`, скругление 16/4/16/16, «ВЫ», голосовой ответ в «ёлочках»; иконка (i) раскрывает технические данные попытки (статус, уверенность Laya, задержка по этапам, Вежливость, Ролевая модель, риск безопасности). Ситуация следующего Шага появляется только после реплики пассажира. Служебные отметки («Время вышло», «Вы решили: …») — мелко по центру |
| Голосовой ответ | `VoiceDock` в `front/src/components/game/trip-game.tsx` | Плашка `card` под диалогом: круглая кнопка 52 px `primary` с ореолом `brand-soft` (запись — `danger` с ореолом `danger-soft` и квадратом), заголовок и подсказка, справа `Countdown` до начала ответа, во время записи — `Stopwatch`. Нажали — запись, нажали ещё раз — отправка («Распознаём речь…», затем «Пассажир отвечает…»). После уточнения пассажира плашка обведена `warning` и просит «Ответьте ещё раз» |
| Выбор игры | `GameList` в `front/src/components/games/game-list.tsx` | Карточки-ссылки по образцу «Выбора режима»: иконка в круге `brand-soft`, название (у Симулятора — пометка «главная игра»), что ждёт одной фразой, «Польза: …» `muted-foreground`, строка-мета бирюзовым (время, формат), справа шеврон. Стоит на Главной и в «Играх» |

Остальные кандидаты из эталонного эскиза: Вариант ответа, карточка Челленджа, строка лидерборда, ячейка тепловой карты, плашка «Рекомендация».
