# UI-kit «Турбо-Бригады»

Прежде чем делать новый UI-компонент, проверьте этот файл: возможно, нужное уже есть. Новые блоки попадают сюда после того, как прототип экрана утверждён.

Стек: Next.js 16, Tailwind CSS v4, shadcn/ui (база Radix, пресет Nova), иконки lucide-react. Код — в [front/](../../front/).

## Тема

Только светлая. Токены лежат в [front/src/app/globals.css](../../front/src/app/globals.css), в классах используются через имена Tailwind: `bg-brand`, `text-danger`, `bg-heat-1` и т. д.

| Токен | Цвет | Где |
|---|---|---|
| `background` | `#ECEBEA` | Фон приложения (фон vsm400.ru) |
| `canvas` | `#E2E0DC` | Поле вокруг телефонной колонки на широком экране |
| `card` | `#FFFFFF` | Карточки |
| `primary`, `foreground` | `#2E354B` | Основные кнопки, текст, тёмные плашки (Рейс дня) |
| `muted-foreground` | `#5E6476` | Второстепенный текст |
| `brand` / `brand-light` / `brand-soft` | `#038681` / `#54AEA4` / `#E0F0EE` | Акцент ВСМ: активные элементы, «верно», прогресс |
| `danger` / `danger-soft` | `#DA2032` / `#FBE3E5` | Срыв рейса, критическая ошибка, падение Шкалы |
| `warning` / `warning-foreground` / `warning-soft` | `#FF6803` / `#A84300` / `#FFE8D9` | Таймер на исходе, Шкала в опасной зоне. Для текста только `warning-foreground` |
| `heat-1…4`, `heat-low` | см. `globals.css` | Тепловая карта: < 50%, 50–64%, 65–79%, ≥ 80%, мало данных |
| `sidebar-*` | `#2E354B` и др. | Тёмное боковое меню рабочего места |

- **Скругление:** `--radius: 0.75rem`. Кнопки `rounded-lg` (12px), карточки `rounded-xl` (~17px, как на vsm400.ru).
- **Шрифт:** Manrope через `next/font/google`. Фирменный MoscowSans Московского транспорта не подключён: лицензия не проверена.
- **Цифры** в колонках и счётчиках: `tabular-nums`.

Откуда цвета: палитра выкачана из CSS vsm400.ru, красный и оранжевый — transport.mos.ru и mosmetro.ru. Эскиз, на котором стиль согласовывали: [etalon.html](etalon.html) (открывается двойным кликом; опубликованная копия — https://claude.ai/artifact/MpZVzEx7VZU2WQW7157oef).

## Шаблоны страниц

Каждый шаблон — layout группы маршрутов в `front/src/app/`.

| Шаблон | Группа | Устройство | Каркас |
|---|---|---|---|
| Вход | `(auth)` | любое | Логотип и одна колонка по центру |
| Приложение проводника | `(player)` | телефон | `PlayerHeader` (аватар, Бригада, колокольчик) + нижние вкладки `PlayerTabBar` |
| Игра | `(game)` | телефон | `GameTopBar` (выход и название). Шкалы и таймер рисует сама игра |
| Рабочее место | `(workspace)` | десктоп | `AppSidebar` (тёмное меню: Аналитика, Контент) + `WorkspaceHeader` |

Компоненты каркаса лежат в `front/src/components/shell/`.

## Карта экранов

Единственный источник — [front/src/lib/screens.ts](../../front/src/lib/screens.ts): путь, шаблон, роль, этап и что должно быть на экране. Из него строятся боковое меню, заголовки и заглушки. Новый экран сначала добавляется туда.

Пока экран не сделан, на его месте `ScreenPlaceholder` — пунктирная карточка «Что здесь будет».

## Компоненты shadcn/ui

Установлены: `avatar`, `badge`, `button`, `card`, `dropdown-menu`, `input`, `progress`, `separator`, `sheet`, `sidebar`, `skeleton`, `tooltip`. Остальные добавляются командой `npx shadcn@latest add <имя>` из папки `front/`.

## Доменные блоки

Появились вместе с экраном Смены на свайпах.

| Блок | Компонент | Правила |
|---|---|---|
| Шкала | `ScaleMeter`, `ScalesPanel` в `front/src/components/game/scale-meter.tsx` | Название, значение, плашка изменения от последнего решения (`−` красным, `+` бирюзовым), полоса с отметкой старта. Цвет полосы: бирюзовый, от половины до четверти над порогом Срыва — `warning`, ниже четверти — `danger`. Общая для всех игр |
| Иконка Темы | `TopicIcon` в `front/src/components/game/topic-icon.tsx` | Иконка lucide на каждую Тему PRD §7.1; у новой Темы из справочника — общая иконка |
| Карточка-свайп | `SwipeCard` в `front/src/components/swipes/swipe-card.tsx` | Одна полярность: вправо — «да / можно / сделать», влево — «нет / нельзя», вверх — «Не знаю». Ответ засчитывается после смещения на 96 px, до порога карточка возвращается. Пока тянут, штамп показывает, каким будет ответ. Сверху — чип Темы, бейдж Класса и «Повтор». Под карточкой всегда кнопки-дубли трёх ответов |
| Пояснение | `VerdictLabel`, `ExplanationText`, `SourceLine` в `front/src/components/swipes/explanation.tsx` | Вердикт: «Верно» бирюзовым, «Неверно» красным, «Не знаю» `warning-foreground`. Ключевой факт жирным, ниже «Источник: …» мелко. После верного ответа — плашка `brand-soft` над следующей карточкой, после ошибки — панель во всю карточку с кнопкой «Понятно» |

Остальные кандидаты из эталонного эскиза: таймер, Вариант ответа, реплика пассажира, кнопка голосового ответа, карточка Челленджа, строка лидерборда, ячейка тепловой карты, плашка «Рекомендация».
