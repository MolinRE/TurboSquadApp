# Ограничения решения и план развития

«Турбо-Бригада» сдана в формате MVP: продукт проходится целиком за всех трёх персонажей (Проводник, Методист, Руководитель), но часть блоков сделана в минимальном объёме. Здесь собраны ограничения MVP и план развития после хакатона. Подробные нерешённые вопросы — в [open-questions.md](open-questions.md), исходный замысел — в [PRD v7](prd-turbo-brigada-v7.md).

## Ограничения MVP

### ИИ и голос

- **Внешние ИИ-сервисы.** Распознавание речи (GigaAM-v3) и LLM работают через внешний российский роутер polza.ai. Для этого нужны интернет и ключ, а расшифровка реплики проводника покидает контур. Аудио не сохраняется.
- **Laya на CPU.** Laya развернута на тестовой ВМ (2 vCPU, 8 RAM), скоринг голосового ответа имеет медиану 1,9 сек. Целевые ~33 мс — это показатель для GPU. На кнопочные Шаги задержка не влияет: их ветвление считает сервер без ИИ. Замер: [feat-communication-scoring/execution.md](feat-communication-scoring/execution.md).
- **Пассажир отвечает текстом.** Синтеза голоса нет, этого не хватает для полного handsfree user flow.
- **Вычистка персональных данных простая.** Регулярные выражения убирают почту, телефон, паспорт и ФИО, и только из текста Источников перед генерацией контента.

### Движок и контент

- Из Шкал подключены только две обязательные: Лояльность пассажира и Рейтинг безопасности. Ресурс проводника, Пунктуальность и Чистота не подключены.
- Условия трёх типов, объединяются только через «И». Условия «случайность» нет.
- Нарушение порядка этапов Ролевой модели общения не штрафуется.
- Контента немного: Заступ на смену, несколько демо-Событий и стартовая колода Вопросов.
- Вопросы генерируются только из вставленного текста, файлы (.pdf, .docx, .xlsx) не принимаются. События генерируются простыми Черновиками, а не многошаговыми графами «под ключ».
- Событие правится в форме поверх JSON. Визуального редактора графа нет.

### Геймификация и аналитика

- Работают профиль с Очками знаний и Званием, 10 Ачивок, лидерборд и рейтинг бригад. Нет уведомлений, Сезонов, Челленджей и Бонуса регулярности.
- В аналитике Руководителя работает только экран голосового конвейера. Тепловая карта Тема × Компетенция, карточки проводников, вовлечённость и качество контента пока показаны заглушками.

### Интеграции и инфраструктура

- Интеграционный API для HR только отдаёт успеваемость Проводников по одному ключу сервиса ([integration.md](integration.md)). Импорта сотрудников, экспорта в xAPI, SSO, биллинга и записи в HR-систему нет.
- Все стенды работают с одной общей базой PostgreSQL на VPS. API запускается одним экземпляром в режиме Development. Работу нескольких экземпляров не проверяли.
- Для ИИ-эндпоинтов нет лимита частоты запросов.
- Есть краевые случаи, которые не ломают демо. Например, после перезагрузки страницы посреди Вопроса обратный отсчёт на экране начинается заново, а незаконченная сессия игры запоминается в браузере без привязки к проводнику. Полный список — в [open-questions.md](open-questions.md), раздел 4.
