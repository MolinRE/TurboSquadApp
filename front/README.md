# Фронт «Турбо-Бригады»

Next.js 16 + TypeScript + Tailwind CSS v4 + shadcn/ui.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

- Тема, шаблоны страниц и компоненты: [docs/ui-kit](../docs/ui-kit/README.md).
- Карта экранов: [src/lib/screens.ts](src/lib/screens.ts).
- Правила для агентов: [AGENTS.md](AGENTS.md).
